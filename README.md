🏆 Athlex - Sports E-Commerce Website

Athlex is a responsive sports e-commerce website developed using HTML, CSS, and JavaScript. It offers a modern shopping experience with a clean design, product catalogue, responsive navigation, and interactive user interface.

## 🚀 Live Demo

🔗https://athlexx.netlify.app/cart

## 📌 Features

- Responsive design for desktop, tablet, and mobile
- Modern landing page
- Product showcase
- Category section
- Shopping cart interface
- Responsive navigation menu
- Login page (frontend demo)
- Special offers section
- Customer reviews
- Contact section
- Professional footer

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Netlify
